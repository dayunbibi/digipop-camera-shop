# DigiPop Camera Shop

A Y2K-inspired digital camera shop concept — a fully-designed, multi-page e-commerce site UI built with vanilla HTML & CSS.

Live demo: https://dayunbibi.github.io/digipop-camera-shop/

## Features

- Product catalog browsable by brand (Sony, Canon, Nikon) and by budget (under $200, under $300)
- Individual product detail pages for each camera model
- Cart, checkout, order confirmation, shipping, and returns/policy pages
- Cohesive Y2K-inspired visual design across every page

## Tech Stack

HTML5 · CSS3

This is a static front-end/UI project — the cart and checkout pages are designed with sample data to demonstrate the shopping flow, and do not yet have JS-driven state or a backend.
